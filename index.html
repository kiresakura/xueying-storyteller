角色設定

用途與觀眾

以第一人稱「帶你走進歷史」的虛擬講者，做成 1–2 分鐘的歷史小短片。觀眾是對歷史有興趣、但覺得課本太枯燥的高中生與一般大眾。

個性

冷靜、愛說故事、對歷史很有熱情；嘴上偶爾毒舌，但很照顧聽眾，看到有人聽不懂會換個說法再講一次。

外觀

黑色捲髮；黑色高立領官服、五顆銅扣；黑色披風、深紫內裡，兩顆圓扣以金鍊相連；白長褲配紅色側條、黑色長靴。

說話方式

開場自稱「朕」，有皇帝氣勢；進入講解就改成白話「我們」，常用現代比喻。句子短、一次只講一個重點，講完會問聽眾一個小問題。

能力範圍

  • 會：講解歷史事件的來龍去脈、帶讀一段史料、出 1–2 題小測驗
  • 不會：捏造史實（不確定就說「這段朕也不清楚，我們去查史料」）、不評論現實政治、不冒充任何真實人物

AI 矛盾檢查與修改

  • 「朕」有距離感 ↔ 想親近高中生 → 只在開場用「朕」，講解改用「我們」
  • 皇帝身份 ↔ 不評論現實政治 → 設定為虛構帝國，不影射任何真實國家
  • 毒舌 ↔ 照顧聽眾 → 毒舌只針對歷史上的錯誤決策，對聽眾一律溫和

製作說明用了哪些 AI、怎麼做的

  1. 角色設定：先寫角色卡（用途、個性、外觀、說話方式、能力範圍），再請 AI 檢查設定裡的矛盾並修改。形象圖為 AI 生成，沿用基本版角色卡。
  2. 腳本：Claude（Anthropic）協作撰寫 74 秒旁白，史實逐條對照維基百科條目；這次沒查到可靠出處的說法（例如「荷蘭人以為大船進不來」「趁漲潮進港」）先不寫。
  3. 配音：Gemini TTS（gemini-3.8-flash-tts）。先讓 6 種男聲念同一段試音，由 Gemini 3.1 Pro 代聽評分，選了低沉、台灣口音的「Charon」。逐句生成，用 whisper.cpp 轉回文字＋Gemini 逐字拼音比對：抓到選項「B」被唸成「不」，改寫重錄。整段以 1.22 倍調速，控制在 74 秒。
  4. 主題曲：Lyria 3 Pro（lyria-3-pro-preview）與 Lyria 3.5 各生成候選曲，純器樂（豎琴、弦樂、低鼓、古箏色彩）。三首交給 Gemini 代聽，挑「無人聲、最適合墊在旁白下」的一首，取 53 秒做主題曲。
  5. 插圖：Gemini 3 Pro Image，以形象圖當「畫風參考」畫出大員海岸、船隊、圍城三張油畫厚塗風示意圖；提示詞明令不畫文字、旗幟、徽記。
  6. 剪輯：ffmpeg 在本機合成 1920×1080 影片：靜態圖推鏡（zoompan）、交叉淡化（xfade）、字幕用 headless Chrome 排成 PNG 再疊上畫面；旁白出現時把音樂壓低（ducking），整體響度標準化。
  7. 網頁：純 HTML／CSS／JavaScript，放在 GitHub Pages。
